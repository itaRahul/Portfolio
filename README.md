# Rahul Sarkar Portfolio

## Files
- `index.html` — portfolio content
- `styles.css` — responsive dark navy/cyan design
- `script.js` — mobile menu and footer year
- `assets/profile.png` — profile portrait

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (or use a separate repository for this portfolio).
2. Upload **all files and the `assets` folder**, keeping the same folder structure.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the generated website URL.

Contact details and social links are included from the information previously shared. Review them before publishing publicly.


## CV
The portfolio includes `assets/Rahul_Sarkar_CV.pdf`. The hero and contact sections have View CV and Download CV links. Keep the PDF in the assets folder when publishing the site.
